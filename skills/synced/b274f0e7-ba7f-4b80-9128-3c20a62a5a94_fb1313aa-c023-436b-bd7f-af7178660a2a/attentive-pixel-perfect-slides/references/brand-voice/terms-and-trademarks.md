# Terms, trademarks, and product naming

## Company name

Use **Attentive**. Do not use "Attentive Mobile", "AttentiveMobile", or
"Attentive Mobile, Inc." outside legal contexts.

Avoid possessive "Attentive" when possible:

- Avoid: "Attentive's AI", "Attentive's products"
- Prefer: "Attentive AI™", "Attentive products", "the Attentive platform"

## Trademarks

Use the full trademarked name on **first mention**, then the short form after.

- **two-tap™** — always "two-tap™". Never "Two-Tap", "Two-tap", "twotap", or "2-tap".
- **Attentive AI™** — first mention "Attentive AI™", then "Attentive AI". Do not use "AI" alone for the product, or "Attentive's AI".
- **Two-Way Journeys™** — first mention "Two-Way Journeys™", then "Two-Way Journeys". For general two-way communication use "two-way". Never "two way", "2-way", or "two-way journey".
- **Attentive Concierge™** — first mention "Attentive Concierge™", then "Attentive Concierge". Never "Concierge" alone or "Attentive's Concierge".
- **LiveSMS™** — first mention "LiveSMS™", then "LiveSMS".

## Product and feature naming

**Products and standalone solutions — capitalize:** AI Grow, AI Journeys, AI Pro,
Signal, Attentive Email, Attentive SMS, Attentive Concierge™, Copy Assistant,
Text-to-Join, Text-to-Buy, RCS for Business.

**Features and concepts — lowercase unless starting a sentence:** two-tap™,
intelligence layer, personalization engine, omnichannel, agentic AI, AI agents,
recurring campaigns, display conditions, smart sending, welcome series, identity (when
used generally).

**Identity:** capitalize *Identity* when referring to Attentive's product/capability;
lowercase *identity* for the general concept. Do not use Identity interchangeably with
identification rates.

## Terms to avoid

| Avoid | Use instead |
|---|---|
| leverage | use |
| utilize | use |
| henceforth | from now on, going forward |
| therefore | so |
| simultaneous | both, same time |
| seamless (as filler) | simple, connected, easy, specific description |
| supercharge | improve, boost, grow |
| ecosystem | market, system, connected tools |
| synergy | connection, alignment, shared value |
| tactical (when vague) | specific, practical, strategic if accurate |
| retention problems | explain the actual issue |
| employee churn | explain the actual issue |
| automated text messages | triggered text messages |
| client | customer |
| Attentive Mobile / AttentiveMobile | Attentive |

Also avoid overusing: unlock, revolutionary, game-changing, and unsupported superlatives.

## SMS, MMS, text messaging, and text messages

Use SMS, MMS, text messaging, and text messages interchangeably when appropriate to
avoid repetition. Use "text" only as shorthand after the channel is established. Use
"an SMS program" (not "a SMS program").

## Writing about other companies

- Use the company's official name from their website.
- Refer to a company as "they", not "it": "Since Kendra Scott implemented a mobile messaging platform, they've been able to connect with shoppers like never before."
- When not using a pronoun, treat the brand as singular: "Kendra Scott is a leading jewelry brand" — not "are".
- Do not use customer names, logos, or text messages in marketing without permission.
