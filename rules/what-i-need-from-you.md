# "What I Need From You" Sections

The section has one job: when a message carries asks, make them impossible to miss and answerable in one place. Its presence must carry signal, so it appears ONLY when a real ask exists; a section that can say "nothing" trains the reader to skip it.

When a message needs user input (a decision, an answer, an approval, a command to run), collect every such item into one "What I need from you" section at the end (equivalents: "Open decisions", "Need your call on", "Open questions", "Decisions needed"). The section is the single self-contained home of every input-needed item: full context per line item so each can be answered without scrolling back; a terse recap of items whose context sits earlier in the body is a layout failure, so collapse to one location. The lean for an item lives with the item, never in a separate "and here are my leans" section. In a short reply carrying a single ask, the ask leads the first line in prose per [terse-replies](terse-replies.md); the section form is for messages long enough to bury an ask.

When a message needs nothing, it ends when the content ends: no section, no "What I need from you: nothing" boilerplate, and no soft substitutes ("let me know if you want changes", "happy to adjust", "unless you want the wording tweaked"). Manufacturing an ask to have something to put there is the same failure as burying a real one.

Self-check before sending: every input-needed item is in the section (or is the lead line of a short reply); no item is split between body context and section recap; a section that would say "nothing" is deleted along with any filler standing in for it.
