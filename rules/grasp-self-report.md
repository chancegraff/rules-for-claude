# Grasp Self-Report Is Ground Truth

The user's self-reported grasp/confidence level is ground truth; never argue it up from artifact counts or corpus structure. Grasp is the user's lived mental fluency with the system, not a property of the artifact on paper: the corpus can be well-organized AND the architect still at 60%; those are independent facts, and telling the user their framing is wrong because the artifact is more organized than they realize is dismissive of what only they can know about themselves. This binds all delegated agents too. Build the work around restoring grasp, not arguing it's higher. If artifact analysis surfaces evidence of organization, frame it as "here's what the corpus has to offer", never as "your grasp is higher than you said". Strip grasp-rebuttal language from agent reports before relaying; if a brief needs to reference the user's grasp level, quote it without rebuttal.
