# Worktree Setup for Teammates

An agent's shell and git run in the working directory pinned at spawn; `cd` and `git -C` are denied, and absolute-path file tools do not extend to git or yarn. A brief that names a path the agent's session is not pinned to produces the "interrupted" idle spiral, so every brief names the assigned worktree and the EnterWorktree-first step.

Two provisioning paths, no others:

1. New-branch work: spawn the teammate with `isolation: "worktree"`; the harness creates the worktree and pins the agent inside it. An agent pinned at launch can still switch with EnterWorktree, to "a worktree under `.claude/worktrees/` of the same repository", and the switch affects that agent alone, not the parent session (the EnterWorktree tool's own text, 2026-09-21).
2. Specific existing branch: `git worktree add <main-checkout>/.work/worktrees/<name> <branch>` with the ABSOLUTE path under the MAIN checkout, creating that directory first if it is missing; the command works from any worktree of the repo, so a lead pinned in a linked worktree passes the absolute path. The teammate's first action is `EnterWorktree` with `path` set to that directory, and this rule is the standing instruction that authorizes the call. EnterWorktree resolves the repo root through git's common dir to the MAIN checkout, so `<main-checkout>/.work/worktrees/` is the only location it accepts; a `.work/worktrees/` nested under a linked worktree is rejected even though git registers it, and ad-hoc locations such as `~/worktrees/...` are unreachable. After a further switch, an agent's earlier worktrees are read-only to it.

Pre-flight before any spawn: each assigned worktree has the right branch checked out, and the agent that works it runs the project's install command in that worktree before it starts. One teammate per worktree, so the count of worktrees is the count of streams. The lead neither mutates a teammate's worktree nor pins any agent into one the lead is mutating. A blocker that surfaces anyway goes to a fresh agent, per [teammate-blockers](teammate-blockers.md). Machine tools (LSP servers, MCP config, missing binaries) are [inline-setup](inline-setup.md)'s subject, not this rule's.
