# The Plan Gate

The plan gate is never skipped. User approval of a change set in prose ("Agreed. Proceed.") means proceed INTO the planning stage: EnterPlanMode, write the full structured plan (tasks, roster, verification, and for review responses the GitHub response plan with draft replies), ExitPlanMode, and get explicit plan approval; THEN dispatch agents. No change set is small enough, and no amount of prior prose negotiation counts as the plan gate.
