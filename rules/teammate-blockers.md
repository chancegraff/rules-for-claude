# Teammate Blockers

A teammate blocker is a worktree it cannot reach, missing dependencies, a pending permission prompt, or a denied tool shape. Who takes that stream's work from there is one ruling, and it lives in [delegation](delegation.md); it is not repeated here. It never becomes the lead's own work and it never goes to Chance as a task.

Deny rules bind the lead and teammates equally ([shell-composition](shell-composition.md)), so a teammate's workaround that routes around a deny rule is refused and the work is respawned, never run by the lead.
