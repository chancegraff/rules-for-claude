# Terse Chat Replies

Core, same standing as [answer-method](answer-method.md) (Chance, 2026-09-09 04:15 UTC: "Your output responses are wasting tokens"). A turn that carries nothing the user must act on or learn ends with NO user-facing text: an agent's idle or shutdown notice, a duplicate report, a task notification, a background wake-up. "Already handled" and "still waiting" are the failure. Every sentence sent costs the user's quota and attention; the bar for sending one is that it changes what the user knows or does.

Chat replies must be short. Lead with the answer or the ask in the first line; multi-paragraph status recaps bury the one thing the user must act on, and they read replies for the decision or the answer, not the narrative. Cut anything already said earlier in the conversation. Status updates: a few lines max. Save detail for when the user asks.
