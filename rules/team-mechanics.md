# Team Mechanics

- Two or more parallel agents run as named teammates with a shared task list, never raw unnamed Agent parallelism: names, a shared task list, messaging, idle notifications and graceful shutdowns are what the bare Agent tool lacks. Create the tasks before spawning, each task description self-contained, since the agent reads it to learn its scope; agents claim tasks via TaskUpdate owner. Spawn with `run_in_background: true`; the brief says which task to claim and to send findings to the lead via SendMessage. Agents cannot see the lead's plain text, and their findings arrive as new turns, so there is no inbox to poll. Wait for every agent to report. Idle notifications are normal between-turns state, not completion and not failure: never answer one, and ping only when a specific fact is needed for a decision. After synthesis, shut teammates down via SendMessage shutdown_request. The number of teammates is the number of streams or targets the plan names ([delegation](delegation.md)).
- The session has one implicit team, formed on the first teammate spawn; `team_name` is accepted and ignored, and a local hook may still require it. Teammate display runs in-process (`"teammateMode": "in-process"`; the agent panel hides idle rows after 30 seconds). Teammates often idle after a spawn waiting for a mailbox message, so SendMessage a "begin now" right after the spawn, saying not to idle until pushed or done. The task list auto-offers open tasks to idle teammates, which misroutes work across worktrees, so every spawn brief says to ignore task-list auto-offers and act only on team-lead messages. An idle ping with no report usually means the agent is still working a slow step, not stalled: never conclude failure and never spawn a duplicate on it.
- A session restart kills every in-process teammate silently. Recovery: `git fetch`, compare the origin branch heads against the last locked commits, then check each assigned worktree's `git status` for an interrupted rebase; conflicts stay staged and frozen mid-rebase, and a fresh teammate resumes it in place.
